# Muhammad Shahroz | Portfolio

Personal portfolio website for Muhammad Shahroz, Business Analytics and Machine Learning.

## Files
- `index.html`: the website
- `images/shahroz.jpg`: profile photo

## Publish on GitHub Pages
1. Create a new public repository (for example `portfolio`, or `USERNAME.github.io` for a root URL).
2. Upload everything in this folder (keep the `images` folder).
3. Go to **Settings > Pages**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then **Save**.
4. After a minute the site is live at `https://USERNAME.github.io/portfolio/` (or `https://USERNAME.github.io/`).
